# Flowly SaaS Customer Intelligence

## Project Overview

Flowly is a fictional B2B SaaS productivity and collaboration platform created for this analytics project.

The project analyzes customer behavior, product engagement, feature adoption, revenue, churn, support experience, and customer retention.

The goal is to demonstrate an end-to-end data analytics workflow using Python, SQL Server, and Tableau.

## Business Problem

The business wants to understand:

- Which customers generate the most revenue?
- Which plans and segments perform differently?
- What is driving customer churn?
- How does engagement relate to retention?
- Which product features are most widely adopted?
- How does customer retention change across signup cohorts?

## Technology Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL Server
- Tableau

## Dataset

The dataset is synthetic and was created specifically for this educational project. It represents fictional Flowly business data and does not contain real customer information.
